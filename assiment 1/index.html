Terminal notes · 01

Bash commands I have learned

A quick reference for the commands I have explored while learning the terminal.

01

touch

File creation

The touch command creates a new, empty file. If the file already exists, it updates the file's last-modified timestamp without changing its content.

$ touch notes.txt

Output: No output. The file is created silently in the current folder.

02

mkdir

Folder creation

The mkdir command creates a new, empty folder (directory) at the location you specify.

$ mkdir project

Output: No output. The folder is created in the current directory.

03

cd

Changing directory

The cd command changes the current working directory, moving you into a different folder in the terminal.

$ cd project

Output: The prompt changes to show that you are inside ~/project.

04

grep

Text exploration

I tried grep "Syntax" index.html to search this page for every line containing the word “Syntax”.

$ grep "Syntax" index.html
Syntax: touch filename
Syntax: mkdir foldername
Syntax: cd foldername

My understanding: grep searches file contents for a word or pattern and prints only the matching lines.
