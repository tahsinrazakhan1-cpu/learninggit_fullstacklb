# Full Stack Development Learning Repository

This repository contains HTML, CSS, and web design practice work created during the Full Stack Development course.

## Project structure

- [Day 1](day-1/index.html) — HTML basics and text formatting practice
- [Day 3 lab](day-3-lab/index3.html) — local image lab and HTML exercises
- [Day 4](day4/day4.html) — HTML and CSS learning files
- [Day 5](day5/day5.html) — navigation and multi-page mini-site work
- [Lab 3](lab%203%20fast/index.html) — page variations and nested-folder exercises
- [Lab 4](lab4/index.html) — forms and additional HTML/CSS practice
- [Worksheet 7](WORKSHEET7/INDEX.html) — description lists and link targets
- [Assignment 1](assignment-1/index.html) — terminal command notes and styling

The small standalone files in the root (`la4.2.html`, `lab4.3.html`, and
`a.txt`) are kept as original experiments. The root [index.html](index.html)
is the main navigation page.

## Notes

- Existing lesson filenames are preserved so old links continue to work.
- Folder names describe the lesson or lab that contains the work.
- New exercises should be added to the closest lesson folder and linked from the root index.
